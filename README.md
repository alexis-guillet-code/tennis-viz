# tennis-viz

Tennis match analysis and data visualisation in Python (pandas + matplotlib).

## Projects

| Script | What it shows |
|---|---|
| `serve_comparison.py` | Serve stats of Medvedev vs Tsitsipas (Shanghai 2026): Medvedev never faced a break point, and the gap came from the 1st serve (85% vs 68% of points won). |

## Run it

```bash
pip install pandas matplotlib
python serve_comparison.py
```

## Data

Match statistics from public sources (ATP Tour, Tennis Tonic). Coming next: historical analysis with Jeff Sackmann's open ATP/WTA datasets.
